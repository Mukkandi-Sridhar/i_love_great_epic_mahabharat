# Project Overview: I Love Great Epic Mahabharat

## 🌟 Concept & Identity
**"I Love Great Epic Mahabharat"** is a premium, "Neo-Divine" e-commerce platform dedicated to preserving and sharing the timeless wisdom of the Mahabharat. It blends ancient spirituality with cutting-edge modern web design to create an immersive, temple-like digital experience.

## 🎨 Visual Aesthetic: "Neo-Divine"
The application features a unique design language crafted to feel both sacred and futuristic:
-   **Palette**: Deep Cosmic Black (`#0a0a0a`) accented with Electric Gold (`#FFD700`) and Mystical Purple glows.
-   **Typography**: Modern Sans-Serif (`Inter`) for readability mixed with Classical Serif (`Playfair Display`) for headings.
-   **Atmosphere**:
    -   **Divine Background**: Floating gold particles and pulsing auras.
    -   **Glassmorphism**: 90% opacity dark glass cards for a premium feel.
    -   **Cinematic Intro**: A "Curtain Reveal" animation with 3D letter-by-letter text effects.
    -   **Interactive Cursor**: Dynamically switches between **Vishnu Tilak** and **Shiva Tilak** on click.

## 🚀 Core Features
1.  **Immersive Exploration**:
    -   **Hero Carousel**: Full-screen cinematic sliders with "Ken Burns" zoom effects.
    -   **Product Showcase**: Ebooks and SD Cards displayed in glowing, interactive 3D cards.
2.  **Seamless Authentication**:
    -   **Google One-Tap**: Instant login via Firebase Authentication.
    -   **Profile Sync**: Automatic synchronization of user data to Firestore.
3.  **Smart Commerce**:
    -   **Ownership Verification**: The app knows what you've bought.
    -   **Dynamic Buttons**: "Buy Now" changes to "View Content" if you own the item.
    -   **Direct Access**: Instant access to Google Drive links for purchased digital goods.
4.  **User Dashboard**:
    -   **Profile Page**: Manage details, view purchases, and access support.
    -   **Collection**: A dedicated library for all your purchased wisdom.

## 🛠️ Technology Stack
-   **Frontend**: React (Vite), TypeScript
-   **Styling**: Tailwind CSS, Tailwind Animate
-   **Backend/Auth**: Firebase (Auth, Firestore)
-   **State Management**: React Query, Context API
-   **Routing**: React Router DOM
-   **Icons**: Lucide React

## 🏃‍♂️ How to Run
The project is built with Vite for lightning-fast performance.

1.  **Install Dependencies**:
    ```bash
    npm install
    ```
2.  **Start Development Server**:
    ```bash
    npm run dev
    ```
3.  **Build for Production**:
    ```bash
    npm run build
    ```
